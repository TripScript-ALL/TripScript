# TripScript

해외여행 영수증과 다중 통화, 카드 수수료, 참여자별 비용을 관리하는 여행 정산 앱입니다.

- `frontend/`: Flutter 앱. [실행 안내](frontend/README.md)
- `backend/`: FastAPI API, OCR 서비스와 운영자 웹. [실행 안내](backend/README.md)
- [공개용 설정 및 실행](PUBLIC_SETUP.md)
- [보안 검토와 배포 전 남은 작업](SECURITY_REVIEW.md)

실제 서버 주소, 비밀키, DB 및 사용자 업로드는 저장소에 포함하지 않습니다.
소스 공개와 운영 서버 배포는 별도입니다. 이 저장소를 올리는 작업은 서버를 배포하거나 변경하지 않습니다.
